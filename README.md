The Home Page of this Udemy Clone website is designed to replicate the basic structure of an online learning platform. It is developed using only HTML and CSS to demonstrate front-end development skills without using any frameworks or JavaScript.
The page includes a responsive navigation bar at the top with sections such as Home, Courses, Categories, and Login. A search bar is also included to simulate the functionality of searching for courses. Below the navigation bar, a banner section is created to highlight featured courses and promotional content.

The main section of the page displays multiple course cards arranged using CSS Flexbox or Grid layout. Each course card contains:

Course image
Course title
Instructor name
Course rating
Price details
The layout is clean and structured, with proper spacing, margins, padding, and alignment. CSS properties such as flexbox, box-shadow, hover effects, and border-radius are used to enhance the visual appearance of the website. The design focuses on simplicity and readability while maintaining a professional look similar to an actual e-learning platform.
Page 2: Course Details / Login Page
The second page of the website represents either a Course Details page or a Login page, depending on the project structure.
If it is a Course Details page, it contains:

Detailed course title
Instructor information
Course description
Course duration
Enrollment button
This page provides more information about a selected course and is styled using CSS for proper content arrangement and typography.
If it is a Login page, it includes:

Username input field
Password input field
Login button
Basic form styling
The form is styled using CSS properties such as padding, border styling, input alignment, and button hover effects to create a clean and user-friendly interface.
🎯 Project Objective
The main objective of this project is to understand the structure of web pages using HTML and improve styling techniques using CSS. It demonstrates knowledge of layout creation, positioning, spacing, card design, and responsive structuring.
This project helps in strengthening basic front-end development concepts and serves as a foundation for building more advanced web applications in the future.
